## 4. Isolated Lab Environment

The system runs in a local isolated environment:

- Location: /opt/lampp/htdocs/System 2
- Network: Localhost only (no external access during testing)
- User: Local developer account
- Forensics isolation: External access disabled during incident simulation

---

## 5. Setup Steps

### Step 1: Start XAMPP

    sudo /opt/lampp/lampp start

Verify:

    sudo /opt/lampp/lampp status

### Step 2: Copy Project

    cd /opt/lampp/htdocs/
    git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git "System 2"
    cd "System 2"

### Step 3: Configure Database

Edit config/database.php with your credentials.

Create the database:

    mysql -u root -p -e "CREATE DATABASE imaging_system;"
    mysql -u root -p imaging_system < database/database.sql

### Step 4: Run Setup Script

    php database/setup_hashes.php

### Step 5: Set Permissions

    chmod 777 uploads/ logs/ backups/

### Step 6: Access the System

Open browser:

    http://localhost/System%202/

Login with:

| Username | Password | Role |
|----------|----------|------|
| admin | admin123 | Admin |

To reset the environment:

    mysql -u root -p -e "DROP DATABASE imaging_system;"
    mysql -u root -p -e "CREATE DATABASE imaging_system;"
    mysql -u root -p imaging_system < database/database.sql
